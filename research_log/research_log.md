## 2026-10-23 guided intake, translation filter, and covers

- Updated the Streamlit guided recommender to ask six optional questions in sequence: enjoyed book, current book, memorable book, preferred genre, current one-word mood, and favorite author. The guided blend uses book/author answers as TF-IDF text clues, genre answers for genre matching, and mapped mood words (`sad`/`quiet` → reflective, `love` → romantic, etc.) for the heuristic mood component. A skip is an empty answer.
- Recommendation display now filters to the 42 active-catalog rows whose Open Library subject metadata explicitly says `Translations into English`. This is a strict evidence-based filter, not complete translation coverage: missing subject tags can exclude real translations. Also, a work-level title can remain in the source language despite the translation subject; the UI states this limitation because the current catalog has no English-edition title field. Edition-level English verification and translated display titles require adding edition metadata.
- Added Open Library cover thumbnails using work OLIDs; covers are shown when available and source links remain on each result. The Covers API documents OLID lookups and its blank-image response when no cover exists: https://openlibrary.org/dev/docs/api/covers.
- Added an experimental guided ranking blend (genre + TF-IDF text + heuristic mood) for the questionnaire answers. Existing genre-only, TF-IDF, and mood methods remain available; no accuracy or relevance improvement is claimed.
- Follow-up: added a cached Google Books fallback for missing Open Library covers. It requests English-language volumes using title/author search, accepts only close title matches (and English result language), and uses the returned thumbnail URL. Configure `GOOGLE_BOOKS_API_KEY` to enable this fallback. Cover lookups cache for seven days; unmatched titles remain without a cover to avoid showing a likely wrong edition.
- Follow-up: reduced the guided intake to three optional questions only: preferred genres, current mood, and favorite author. The guided ranking uses those answers; previously saved longer questionnaire prompts were removed from the UI.

## 2026-11-06 human evaluation packet and normalization notes

- The prior `profile_recommendation_ratings.csv` and `profile_method_comparison.json` contain AI-assisted metadata-fit proxy scores, not independent reader judgments. They are retained for provenance but superseded as an evaluation design; their scores must not support a claim that TF-IDF or mood weighting improves relevance.
- Added `src/evaluation/prepare_human_comparison.py`. Running `python3 -m src.evaluation.prepare_human_comparison` generates a seeded, 96-row blinded rating packet for the same four fixed profiles and all four engine methods (`genre`, `tfidf`, `mood`, `guided`). It samples the top three recommendations in each profile/method × usable-description/no-usable-description stratum. The usable-description threshold is 50 words. The generated protocol records the active catalog SHA-256 and explains that the sample covers top-ranked outputs only.
- Human ratings are pending. `results/experiments/human_comparison_ratings.csv` has blank relevance and mood-accuracy fields; `human_comparison_key.csv` must be kept from raters until they finish; `human_comparison_protocol.json` records settings. The prior AI-assisted mood sheet is not the new independent human review. No human judgment, agreement score, or method winner is claimed in this update.
- Subject normalization is now documented in `results/experiments/README.md`: the 9,609 distinct trimmed subject strings are otherwise retained verbatim; runtime matching case-folds and extracts ASCII alphanumeric tokens and uses exact token overlap, without synonym, hierarchy, stemming, or language normalization. This can create noisy genre matches.
- Method settings remain in `src/recommendation/engine.py`: genre uses token coverage; TF-IDF blends 0.5 genre and 0.5 cosine similarity; mood blends 0.7 genre and 0.3 mood-token coverage; guided blends 0.5 genre, 0.3 TF-IDF, and 0.2 mood. For this fixed-profile comparison, guided uses the profile genre and mood text; it does not represent personalized free-text answers from live users.

## 2026-11-06 recommendation relevance and stale settings fix

- In response to a UI report that recommendations did not match user inputs, changed the guided app's default candidate pool from the 42 explicitly tagged translation records to the full active catalog. The translation-only subset remains available as a sidebar filter and its coverage limitation is described in the UI.
- Recognized genre concepts now take precedence over conversational filler in the genre query. In the app, if at least one candidate has a genre-token match, only candidates with genre evidence are eligible for the top five, preventing TF-IDF similarity alone from surfacing books with no matching genre subject.
- Profile, ranking method, and catalog-scope changes now rerank the saved recommendation set. Previously the sidebar could change while old recommendation cards remained in chat, making the displayed method/input context misleading.
- This improves explicit genre alignment, but source subject labels remain noisy and mood/author-only preferences can still be weakly represented. The independent rating packet remains necessary before claiming relevance improvement.
